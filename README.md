# Tic-Tac-Toe

A responsive, single-page Tic-Tac-Toe game where you play as **X** against the computer (**O**).

## Features

- Unbeatable computer opponent using the Minimax algorithm.
- Win, loss, and draw detection with the winning line highlighted.
- Scoreboard for wins, draws, and computer wins.
- New game and reset score controls.
- Responsive layout and accessible board controls.
- No framework, dependencies, backend, or build step required.

## Run locally

Open `index.html` in any modern web browser.

## Deploy

This is a static website. It can be deployed directly to Vercel, GitHub Pages, or any static hosting provider. For Vercel, use the repository root as the project root and leave the framework preset as **Other** (no build command required).
